# CSS Selectors Task

This project is created as part of the TuteDude MERN Stack course.

## Task
The purpose of this task is to practice different CSS selectors.

## Concepts Used
- Element Selector
- Class Selector
- ID Selector
- Descendant Selector
- `nth-child()` Selector
- CSS Colors
- Background Colors
- Font Size

- `style.css` – Contains all CSS styling.
